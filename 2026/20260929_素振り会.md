## ペアプロ
- ヒビキさんのAWS EC2環境にあるisucon13のgitリポジトリのコードをgithubリポジトリに登録
  - ドライバー　ヒビキさん、　ナビゲーター　ひでたん
  - まずgithubで新規の空リポジトリを作成（レギュレーションに従って競技中は公開NGのため**Private**にする！）
  - AWS EC2にログイン(ISUCON13のgitリポジトリは作成済み)
  - リモートURLを設定する
```
$ git remote set-url origin git@github.com:ChallengeClub/isucon13_20260929.git
$ git remote -v
```
  - ~/isucon13/.gitignoreを設定する。（必要なwebapp以外を除外）
```　
/*
!/webapp/

# Runtime / build artifacts
/webapp/*.log
/webapp/**/tmp/
/webapp/**/cache/
/webapp/**/bin/
```
  - ~/isucon13/webapp/.gitignoreを設定する。（使わない言語を除外）
```
/public/
/log/
/node/
/perl/
/php/
/ruby/
```
  - githubと接続試験
  - $ ssh -i ~/.ssh/secretkey.pem -T git@github.com
  - ちゃんと接続できる様なら ~/.ssh/configに以下を追記
```
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/secretkey.pem 
  IdentitiesOnly yes
```
  - pushしてみる。
    - $ git push -u origin main
  - git@github.com:ChallengeClub/isucon13_20260929.gitに[ISUCONチーム](https://github.com/orgs/ChallengeClub/teams/isucon)のアクセス権を追加する。
  - チームメンバはcloneしてみる。
    - $ git clone git@github.com:ChallengeClub/isucon13_20260929.git
  - 以上で**コード共有に成功！**
