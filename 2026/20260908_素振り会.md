## ペアプロ練習 
- ペアプロ＝ドライバー：ヒビキさん、ナビゲータ：ひでたん
- ISUCON13攻略で、AWS上で動いているSQLを触ってみる。
  ```
  $ mysql -u isucon -p                     # MySQLに接続する。パスワードはisucon。
  mysql> show databases;                   # DB一覧...ISUPIPEやISUDNSが有る。
  mysql> use ISUPIPE;                      # DB接続...今日はISUPIPEを調べる。
  mysql> show tables;                      # TABLE一覧...livestreamsやlivecommentsが重要そう。
  mysql> describe livestreams;              # TABLE構造概要が判る。idのみKey(Index)がある。
  mysql> SHOW TABLE STATUS FROM ISUPIPE LIKE livecomments;
   # TABLE状態概要が判る。1000行くらいあった。
  mysql> select * from livecomments limit 10;
   # コメントを10件表示する。
  mysql> select * from livecomment where livestream_id = 10 limit 10;
   # 指定したlivestream_idのコメントを10件表示する。
  mysql> explain select * from livecomment where livestream_id = 10 limit 10;
   # クエリの実行計画を表示する。Key=NULLで1000件を検索。
  mysql> select * from livecomment where id = 10 limit 10;
   # 指定したidのコメントを10件表示する。
  mysql> explain select * from livecomment where id = 10 limit 10;
   # クエリの実行計画を表示する。使えるKey(Index)があって1件でヒットする。
  ```
