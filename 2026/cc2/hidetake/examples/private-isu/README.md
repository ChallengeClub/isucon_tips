# private-isu操作の参考例

状態：チーム確認待ち。

公開教材private-isuの例外的なbackend言語（Ruby）で検証した処理です。初回benchmarkと、指定SHAのソース・静的ファイル配備、snapshot復元を含みます。Goなど他言語のビルド・実行ファイル配備には対応していません。

## 利用方法

1. 対象がこの実装と同じ構成か確認します。他問題へはそのまま使いません。
2. scripts/・ansible/を非公開targetリポジトリ直下へコピーし、RUNBOOK.mdをdocs/RUNBOOK.mdへ取り込みます。既存ファイルを上書きせず、差分を確認します。
3. scripts/config.shとansible/settings.jsonを設定し、配置・service・依存定義を確認します。未設定なら実行前に停止します。
4. [操作手順と検証範囲](RUNBOOK.md)に沿って、承認後に検証します。

ここで直接実行せず、非公開targetへコピーしてから利用します。設定分離後はローカル模擬検証のみで、元の実装をprivate-isuで試行しました。
実環境のIP・認証情報・測定ログ・バックアップは含みません。内容hashと権限の復元は確認済みですが、異なる機能変更・依存更新・DB復旧は未検証です。
