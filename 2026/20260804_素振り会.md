## 今日やってみたこと！
  - **bench -> CICD -> benchしてパフォーマンスアップ** をまず試す！
  - Driver: モリアイさん
  - Navigator： アワノさん
  - AMIからEC2を起動する。
    - 過去問のAMIを使って起動。[ここ](https://github.com/matsuu/aws-isucon)の下の方にある。本日はISUCON14。すると自分のAWS環境でインスタンス作成画面が起動する。
    - セキュリティグループ指定では「セキュリティグループ作成」を選ぶ。この時「SSHのトラフィック許可」を「自分のIPアドレス」にすると安全なアクセスになります。
    - 公開鍵ペアも指定します。
    - インスタンスは、まずはt3.microで作成してOK。
  - クライアント準備　（クライアント環境としてgithub codespacesを準備します）
    - githubに空のprivarteリポジトリを作り、そのリポジトリ内にあるcreate codeを押す。
    - 起動したcodespacesのコンソール経由で、秘密鍵ファイル（pemファイル）を置く。Permissionを600に変更。
    - codespacesの外部IPアドレスをEC2インスタンスのセキュリティグループに追加する。（自分環境の外部IPアドレスを調べるには、$ curl ifconfig.meが便利。）
    - $ ssh ubuntu@<ip-address> -i key.pem で接続する。
  - ログインしてbenchを実施してみる
    - $ sudo -i -u isucon
    - $ ./bench run . run --addr 127.0.0.1:443 --target https://isuride.xiv.isucon.net --payment-url http://127.0.0.1:12346 --payment-bind-port 12346
    - t3.microで実行するにはbenchはちと重すぎるかも…💦
  - 以上環境構築＋ベンチマークまでやりました！
