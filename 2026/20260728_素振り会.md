# private-isuチャレンジ
## リポジトリの取得
- `https://github.com/catatsuy/private-isu`
## docker環境の構築
- 自分の場合はdocker engineを使用
## データベースの取得
```shell
cd private-isu
make init
```

### unzipがないと怒られたとき

```shell
sudo apt-get install zip unzip
```

## webapp起動
```shell
cd webapp
docker compose up -d
```
### ポート競合が発生した場合

[READMEのポートの競合](https://github.com/catatsuy/private-isu#%E3%83%9D%E3%83%BC%E3%83%88%E3%81%AE%E7%AB%B6%E5%90%88)を参照

## 待つ、結構待つ

成功した場合は`http://localhost:8080/`にアクセスすると以下のページが出る。
